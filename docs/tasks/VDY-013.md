## Yerel Codex kurulumu — yapılacak (Windows, bu worktree'de)
1. `git status --short --branch` ve `git rev-parse --short HEAD`: doğru worktree ve korunacak yerel dosyalar. Windows PowerShell için `npx.cmd` kullan.
2. `npx.cmd skills --help`, `npx.cmd skills list -a codex`, `npx.cmd skills find react native accessibility` — gerçek çıktıları raporla. Find-skills listede yoksa `npx.cmd skills add vercel-labs/skills --skill find-skills -a codex -y`. Var olan dosyaları körlemesine ezme.
3. Resmî UI UX Pro Max kaynak ve kurulumu kontrol et. `npx.cmd ui-ux-pro-max-cli init --ai codex` ile kurulum yap; ayrıca `npx.cmd skills add nextlevelbuilder/ui-ux-pro-max-skill --list` alternatifinin tüm `scripts/` ve `data/` dosyalarını içerip içermediğini değerlendir. Aynı beceriyi iki kez kurma.
4. `npx.cmd skills list -a codex` ile ikisinin de tanındığını doğrula. Python 3 sürümünü `python --version` ile doğrula; yoksa işletim sistemi kurulumunu kendi başına yapma.
5. `Test-Path .agents/skills/ui-ux-pro-max/scripts/search.py` ve `Test-Path .agents/skills/ui-ux-pro-max/SKILL.md`. Kurulum farklı dizinse gerçek yolu keşfet ve kaydet.
6. Gerçek betik smoke testi: `python .agents/skills/ui-ux-pro-max/scripts/search.py "shift work mobile dashboard" --design-system` (parametreler mevcut SKILL.md ile doğrulandıktan sonra); kaynakların erişilebilir olması, anlamlı stil/UX önerisi döndürmesi ve exit code 0.
7. Yeni Codex oturumu aç: "Vardiyam Takvim/gün panelinde iki Kaydet yerine tek Kaydet ve kısa erişilebilir durum seçenekleri tasarla; hangi skill'leri kullandığını ve gerçek komut çıktısını göster." Sonuçta yalnız tavsiye üret; kod ve kullanıcı verilerini bu smoke sırasında değiştirme.
8. Kaynak/sürüm, dosya listesi, gerçek stdout/stderr, exit code, hangi skill okundu ve bir Vardiyam UX önerisini bu belgeye ekle. Gerçek test yokken PASS yazma.
