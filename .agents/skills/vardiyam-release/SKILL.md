# Vardiyam Release — v1.0

1. Confirm the release task, branch, clean/known diff, version, and exact build artifact.
2. Verify applicable CI, Android/iOS device smoke, purchase/restore sandbox, privacy disclosures, and rollback path; record missing evidence as BLOCKED/SKIP.
3. Check open P0/P1 risks and required legal/privacy review. Never claim legal compliance without qualified review.
4. Production release, store submission, or publishing requires explicit founder approval. Do not push to `main`, merge a PR, or release without it.
